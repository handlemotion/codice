# Security policy

Please do not report vulnerabilities in public issues or pull requests.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/handlemotion/codice/security/advisories/new)
for this repository. Include what is affected, how to reproduce it and its impact. You will get an
answer as soon as possible, and a fix will be released before the details are made public.

Only the latest code on `main`, which is what runs on `codice.io`, is supported.
