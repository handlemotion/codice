---
title: Referencia de la API
description: Cada ruta de la API, con sus parámetros, respuestas y una consola para probarla.
---

Cada ruta de `https://codice.io/v1` tiene su página, generada de la misma definición que usa la API, así que siempre coincide con lo que responde.

Para probar una ruta desde aquí, pon tu clave en la consola de la página. Lee primero [HTTP](/docs/http) para la autenticación, los errores y los límites.
