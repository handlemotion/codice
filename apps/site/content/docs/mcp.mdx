Códice es un servidor [MCP](https://modelcontextprotocol.io), el estándar para darle herramientas a un asistente de IA. Conectado, tu asistente consulta la regla en vez de recordarla, y la cita con su fuente y su vigencia.

Sin Códice, un asistente responde de memoria: puede citar una regla que ya cambió o inventar un atributo. Con Códice, busca el pasaje del SAT vigente y lo cita tal cual.

## Conexión

El servidor está en `https://codice.io/mcp`. Agrégalo a tu asistente con esa dirección y nada más: la primera vez, el asistente abre Códice en tu navegador, entras con tu cuenta y apruebas la conexión. No hay claves que copiar.

### Claude, Grok y otros asistentes con conectores

Agrega un conector personalizado con la dirección `https://codice.io/mcp` y sigue el inicio de sesión. Paso a paso: [Claude](/docs/claude) y [Grok](/docs/grok).

### Cursor, VS Code y otros clientes con archivo JSON

```json
{
  "mcpServers": {
    "codice": { "url": "https://codice.io/mcp" }
  }
}
```

### Claude Code

```bash
claude mcp add --transport http codice https://codice.io/mcp
```

Luego, en Claude Code, abre `/mcp` y elige Códice para iniciar sesión.

### Con una clave

Si tu cliente no inicia sesión por OAuth, o lo conectas desde un servidor sin navegador, manda una clave de tu equipo en el encabezado `Authorization`. Crea una en [Claves](/keys).

```json
{
  "mcpServers": {
    "codice": {
      "url": "https://codice.io/mcp",
      "headers": { "Authorization": "Bearer cdc_…" }
    }
  }
}
```

### Desconectar un asistente

Cada asistente que apruebas queda conectado hasta que lo desconectes desde tu panel en Códice. Al desconectarlo, deja de tener acceso en menos de un minuto.

## Herramientas

Todas son de solo lectura: consultan, nunca modifican nada.

| Herramienta      | Para qué                                  | Argumentos                                          |
| ---------------- | ----------------------------------------- | --------------------------------------------------- |
| `search`         | Busca reglas por pregunta o por clave.    | `q`, y opcionales `asOf`, `source`, `kind`, `limit` |
| `read_passage`   | Lee una regla completa por su id.         | `id`                                                |
| `lookup_error`   | Explica un código de error `CFDI40xxx`.   | `code`                                              |
| `lookup_catalog` | Busca una clave en un catálogo del SAT.   | `name`, `key`, y opcional `where`                   |
| `search_catalog` | Busca claves de un catálogo por su texto. | `name`, `q`, y opcional `limit`                     |
| `list_sources`   | Lista los documentos que contiene Códice. | Ninguno                                             |

Son las mismas consultas que la API, con los mismos argumentos. `where` filtra las claves que se repiten, como en la API: `{ "c_CodigoPostal": "01000" }` para una colonia. Ver [Catálogos del SAT](/docs/catalogos#claves-que-se-repiten). `search_catalog` encuentra la clave cuando solo sabes qué es: `{ "name": "c_ClaveProdServ", "q": "servicios de consultoría" }`; ver [Buscar por descripción](/docs/catalogos#buscar-por-descripción).

## Qué preguntarle

- "El SAT me rechazó una factura con CFDI40149, ¿qué hago?"
- "¿Qué uso de CFDI le pongo a una factura de honorarios médicos?"
- "¿Qué régimen fiscal es el 626 y lo puede usar una persona moral?"
- "¿Qué clave de producto o servicio uso para una factura de consultoría fiscal?"
- "¿Cuál era el plazo para cancelar un CFDI en junio de 2025?"

El asistente decide qué herramientas usar: busca, lee el pasaje y responde citando la fuente.

## Respuestas y errores

Cada herramienta devuelve el mismo `data` que la ruta de la API, como contenido estructurado y como texto JSON. Cuando una consulta no encuentra nada o está mal formada, la herramienta responde con un error (`isError`) que trae el mismo `code` y estado que la API, por ejemplo `error_code_not_found`.

## Límites

Conectado con tu cuenta, tus asistentes comparten un límite de 60 consultas por minuto. Con una clave, las consultas por MCP cuentan contra el mismo límite que la API: 60 por minuto por clave. Un asistente puede hacer varias consultas por pregunta, así que usa una clave aparte para él.
