Códice es un servidor [MCP](https://modelcontextprotocol.io), el estándar para darle herramientas a un asistente de IA. Conectado, tu asistente consulta la regla en vez de recordarla, y la cita con su fuente y su vigencia.

Sin Códice, un asistente responde de memoria: puede citar una regla que ya cambió o inventar un atributo. Con Códice, busca el pasaje del SAT vigente y lo cita tal cual.

## Conexión

El servidor está en `https://codice.io/mcp`. Agrégalo a tu asistente con esa dirección y nada más: la primera vez, el asistente abre Códice en tu navegador, entras con tu cuenta y apruebas la conexión. No hay claves que copiar.

### Claude, Grok y otros asistentes con conectores

Agrega un conector personalizado con la dirección `https://codice.io/mcp` y sigue el inicio de sesión. Paso a paso: [Claude](/docs/claude) y [Grok](/docs/grok).

### Cursor, VS Code y otros clientes con archivo JSON

```json
{
  "mcpServers": {
    "codice": { "url": "https://codice.io/mcp" }
  }
}
```

### Claude Code

```bash
claude mcp add --transport http codice https://codice.io/mcp
```

Luego, en Claude Code, abre `/mcp` y elige Códice para iniciar sesión.

### Con una clave

Si tu cliente no inicia sesión por OAuth, o lo conectas desde un servidor sin navegador, manda una clave de tu equipo en el encabezado `Authorization`. Crea una en [Claves](/keys).

```json
{
  "mcpServers": {
    "codice": {
      "url": "https://codice.io/mcp",
      "headers": { "Authorization": "Bearer cdc_…" }
    }
  }
}
```

### Desconectar un asistente

Cada asistente que apruebas queda conectado hasta que lo desconectes desde tu panel en Códice. Al desconectarlo, deja de tener acceso en menos de un minuto.

## Herramientas

Todas son de solo lectura: consultan, nunca modifican nada.

| Herramienta      | Para qué                                        | Argumentos                                                    |
| ---------------- | ----------------------------------------------- | ------------------------------------------------------------- |
| `search`         | Busca reglas por pregunta o por clave.          | `q`, y opcionales `asOf`, `source`, `kind`, `limit`, `format` |
| `read_passage`   | Lee una regla completa por su id.               | `id`                                                          |
| `lookup_error`   | Explica hasta 25 códigos de error `CFDI40xxx`.  | `codes`                                                       |
| `lookup_catalog` | Busca hasta 25 claves en los catálogos del SAT. | `lookups`: una lista de `{ name, key, where }`                |
| `list_sources`   | Lista los documentos que contiene Códice.       | Ninguno                                                       |
| `list_changes`   | Lista qué reglas cambiaron en un periodo.       | `since`, y opcionales `until`, `source`                       |

Son las mismas consultas que la API. Una diferencia: por MCP, `search` responde breve por omisión (`format: brief`), con la ruta de títulos de cada pasaje y un extracto exacto de su texto; el asistente lee el que responde con `read_passage`, y un pasaje corto llega entero en el extracto. Así cada búsqueda ocupa entre 30% y 70% menos del contexto del asistente. Con `format: full` recibe el texto que coincidió y su fuente, como la API (ver [Resultados breves](/docs/buscar#resultados-breves)). `source` en `search` es un id o una lista de ids: `["anexo-20-guia-de-llenado", "matriz-de-errores-cfdi-40"]`. `lookup_error` y `lookup_catalog` reciben varios códigos o claves a la vez, para revisar un comprobante completo en una sola llamada: `{ "codes": ["CFDI40149", "CFDI40147"] }`, o `{ "lookups": [{ "name": "c_UsoCFDI", "key": "G03" }, { "name": "c_RegimenFiscal", "key": "601" }] }`. `where` filtra las claves que se repiten, como en la API: `{ "c_CodigoPostal": "01000" }` para una colonia. Ver [Códigos de error](/docs/errores#varios-códigos-a-la-vez) y [Catálogos del SAT](/docs/catalogos#varias-claves-a-la-vez). `list_changes` se explica en [Cambios en las reglas](/docs/cambios).

## Qué preguntarle

- "El SAT me rechazó una factura con CFDI40149, ¿qué hago?"
- "¿Qué uso de CFDI le pongo a una factura de honorarios médicos?"
- "¿Qué régimen fiscal es el 626 y lo puede usar una persona moral?"
- "¿Cuál era el plazo para cancelar un CFDI en junio de 2025?"

El asistente decide qué herramientas usar: busca, lee el pasaje y responde citando la fuente.

## Respuestas y errores

Cada herramienta devuelve el mismo `data` que la ruta de la API, como contenido estructurado y como texto JSON. Cuando una consulta no encuentra nada o está mal formada, la herramienta responde con un error (`isError`) que trae el mismo `code` y estado que la API, por ejemplo `passage_not_found`.

`lookup_error` y `lookup_catalog` responden `results`, uno por código o clave y en el orden en que los pediste. Cada resultado trae `data` (lo que devolvería la API) o `error` con su `code`, `message` y `status`, así que un código que no existe no hace fallar a los demás. Solo una lista vacía, de más de 25 o con un argumento mal formado hace fallar la llamada completa.

## Límites

Conectado con tu cuenta, tus asistentes comparten un límite de 60 consultas por minuto. Con una clave, las consultas por MCP cuentan contra el mismo límite que la API: 60 por minuto por clave. Una llamada que consulta varios códigos o claves cuenta como una sola. Un asistente puede hacer varias consultas por pregunta, así que usa una clave aparte para él.
