# Códice (`apps/api`)

Scoped to `apps/api`. Extends the root `AGENTS.md`, which still applies.

Cloudflare Worker (`@codice/api`) for Códice: a searchable index of Mexican tax (SAT)
and customs rules, served over HTTP and MCP. Read `SPEC.md` before changing behavior; update it when
the behavior changes.

- Phase 0 (SPEC.md, "Rollout"): `/v1/search`, `/v1/passages/:id`, `/v1/sources`,
  `/v1/sources/:id`, `/v1/errors/:code`, `/v1/catalogs/:name`, `/v1/catalogs/:name/:key`, their
  MCP tools at `/mcp`, and the `CodiceKnowledge` entrypoint the Agent binds as `CODICE` (SPEC.md,
  "Internal entrypoint"; change it and `@codice/contracts` together, and keep Transitive's
  mirror `@transitive/api-contracts/codice` in step). The ingestion loads `docs/sat-md` into AI
  Search and D1, including the RMF (Phase 1's first source, one passage a regla). Since the cutover (2026-10-25, `docs/operations/cutover.md`) the Cloudflare Git
  build of this repository's `main` deploys the Worker `codice-api` on the Handle account (root `apps/api`, deploy command
  `pnpm run deploy:production`; SPEC.md, "Go-live checklist"), and `codice-corpus.yml` and
  `sync-worker-secrets.yml` run from here. No route or custom domain yet, and `codice.io` is not
  purchased; attaching it needs explicit approval.
- Search is AI Search's: never add chunking, embedding or ranking code here. Change the instance's
  settings only with a retrieval eval run (`pnpm --filter @codice/api eval`) recorded
  in SPEC.md.
- `POST /v1/chat` (SPEC.md, "Chat") is the site's assistant: Claude Sonnet 5.5 through TanStack
  AI with read-only tools over the same handlers, answering briefly from the tools, citing them and
  declining off-topic questions and tax advice. Keep it stateless; a model, prompt or limit change
  updates SPEC.md. Tests stub the Anthropic API; prove an answer with a real call
  (`ANTHROPIC_API_KEY` in the Worker's env).
- D1 schema is Drizzle in `src/db/schema.ts`; change it, then `db:generate`. Never hand-write
  `migrations/`, and never run `db:migrate:remote` yourself: it runs in `deploy:production`.
- Every response carries `x-request-id`. `/v1` bodies use `apiJson` (`src/http.ts`), errors use
  `problem` (throw `CodiceProblem` from a handler). `/v1/*` requires a team's API key and `/mcp/*`
  an OAuth access token or a key, both verified by `codice-app` over the `ACCOUNTS` binding, then
  pass `CODICE_PUBLIC_RATE_LIMITER` keyed by the key id or the OAuth user (SPEC.md, "Auth", "MCP
  authorization", "Rate limiting"). `/.well-known/oauth-protected-resource` (and `/mcp` under it)
  is `/mcp`'s OAuth metadata. Tests stub `ACCOUNTS` with `test/accounts-stub.js`: any
  `cdc_test_<id>` key is valid, and so is any `at_test_<user>` access token.
- `wrangler dev` reaches the real AI Search instance (`"remote": true`): a local search is a real,
  billed query. Tests use a local binding and never prove retrieval.
- Local run: `pnpm dev:up` starts Códice on `https://codice.localhost`, applies the local
  D1 migrations and seeds the records with `ingest --local` when the local D1 is empty;
  `pnpm dev:restart` restarts it. The remote binding needs Wrangler's Cloudflare auth
  (`wrangler login`, or `CLOUDFLARE_API_TOKEN` with Workers Scripts: Edit), not the read-only
  Doppler `dev` token. Details and the check calls: `docs/development/local-development.md`,
  "Códice".
- What comes next, in order: SPEC.md, "Next steps". Tick items off there when they land.
- Answers quote the regulator's text verbatim with its source and validity dates. Never
  paraphrase a rule into a stored passage.
- `docs/sat-md` (all but its README) is generated by `sat:knowledge` from the SAT's published
  files; never edit it by hand, and commit the regenerated set with `sources.json`. A splitter
  change (`scripts/sections.ts`) changes passage keys, which the Agent's citations hold.

Commands: `pnpm --filter @codice/api test`, `check-types`, `build`, `cf-typegen`,
`db:generate`, `db:migrate:local`, `sat:knowledge` (`--check`, `--force`; needs LibreOffice,
MarkItDown and Poppler), `dev` and `eval` (Doppler `codice` `dev`; `eval` spends ~170 AI Search
queries; `--instance` for a comparison instance), and `ingest` (`--dry-run`, `--local`,
`--catalogs` for the large catalogs, `--instance`; writes production, so run it under
`doppler run -p codice -c prd --`).
